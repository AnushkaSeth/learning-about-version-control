# Learning about Version Control
Solving merge conflicts takes conscious effort, but I can do it!

**What I like most:** My favorite thing about version control is the peace of mind it gives me to experiment freely, knowing I can always roll back to a working version if something breaks.

**What I find most challenging:** The most frustrating part of version control is resolving messy merge conflicts when multiple people edit the exact same lines of code, as it is easy to accidentally overwrite someone else's work.
